# 筹码实验室 · Hold’em Lab

中文、免登录的六人桌无限注德州扑克练习工具。基于 MIT 开源 Poker Mentor 固定版本改造，只使用练习筹码。

## 使用

- **实战牌桌**：对战五类电脑对手。盲注 5/10、初始 1,000 筹码；每次行动后暂停，可查看当时的信息与范围分析，再点“继续牌局”。
- **专项训练**：60 题，覆盖补牌与概率、底池赔率、跟注 EV、诈唬门槛、下注金额、范围权益。先提交答案，再显示过程；可只练错题。
- **扑克术语**：标准中英文、定义、例子、位置图，支持搜索 All-in 等术语。
- **牌局复盘**：逐步回放最近的牌谱；计算使用当时冻结的信息，不偷看未来牌。
- **设置与离线**：调整难度和速度、检查缓存、导出与导入本机记录。

## iPhone 安装和离线验收

1. 用 iPhone Safari 联网打开部署链接（见交付消息）。目标支持 iOS 17 及以上。
2. 点分享 → 添加到主屏幕；若有“作为网页 App 打开”，保持开启。
3. 从主屏幕启动，等待顶部出现“已可离线使用”。不要仅凭页面已经显示就断网。
4. 开始一手实战，做一次行动、阅读解析；再练一题，搜索一次术语。
5. 开启飞行模式，从主屏幕关闭并重新打开应用，确认牌桌、练习、术语及本地计算仍可用。
6. 刷新或重开应恢复当前牌局和进度；完整打完一手后，在复盘页逐步查看。
7. 到“设置与离线”导出 JSON，保存到“文件”。导入会先验证并要求确认替换。

iOS 清理网站数据或存储不足时，缓存和记录可能被移除。再次联网可重新缓存；JSON 可恢复进度。新版本下载完成后，等当前手结束再点“应用更新”。尚未完成 iPhone 真机认证，不能用桌面响应式检查替代第 5 步。

## 本地运行

要求 Node.js 24（本版验证版本为 24.18.0）。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

打开 `http://127.0.0.1:4173/`。生产构建会生成版本化离线资源。开发命令 `npm run dev` 适合改代码，但不用于验收离线缓存。手机不能通过自己的 `127.0.0.1` 访问电脑服务器；应使用部署的 HTTPS 链接。

## 如何理解计算

当前池 P 已包含对手下注，尚未包含本次跟注 C。普通静态摊牌模型：

- 所需权益 = C / (P + C)
- 跟注 EV = Equity × (P + C) − C
- 例：下注前池 100，对手下注 50，你跟 50；P=150、C=50，所需权益 25%。若权益 30%，EV=+10。

真实全下按有资格争夺的底池逐层计算。仍有对手待回应时，分层只是临时估算。Equity 包括平局份额，不等于独赢概率；成牌概率也不等于权益。三档对手范围均为示例，不代表机器人真实范围。
